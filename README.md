## 🌟 Overview
**Beluga Health** is a comprehensive, offline-first mobile application designed to act as a personal nursing assistant. Whether you're managing health schedules for yourself or a loved one, Beluga Health ensures that you never miss a beat—from taking medications on time to attending crucial health checkups.

> **Why Offline?** We believe health management shouldn't depend on internet connectivity. All your data stays securely on your device, ensuring maximum privacy and reliability.

---

## ✨ Features

💊 **Medication Reminders**
Set precise alarms for your daily pills. Receive local push notifications even if the app is closed.

🥗 **Meal Planning & Tracking**
Schedule breakfasts, lunches, dinners, and snacks. Keep track of nutrition routines.

📅 **Checkup & Appointment Scheduling**
Visualize your upcoming doctor visits with an intuitive calendar interface.

📂 **Medical Records Management**
Attach files, documents, and images (prescriptions, test results) right into the app.

📤 **Easy Export & Sharing**
Securely share your health reports or schedule with doctors and family members.

## 🛠️ Tech Stack & Architecture

- **Framework:** [Flutter](https://flutter.dev) (Dart)
- **Local Database:** `sqflite` (SQLite for secure on-device storage)
- **Notifications:** `flutter_local_notifications` & `flutter_timezone`
- **Calendar UI:** `table_calendar`
- **Media & Files:** `image_picker` & `file_picker`
- **Sharing:** `share_plus`

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

- Flutter SDK (v3.4.0 or higher)
- Dart SDK
- Android Studio or Visual Studio Code

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Vish-nath/Beluga.git
   cd Beluga/mobile
   ```

2. **Fetch dependencies:**
   ```bash
   flutter pub get
   ```

3. **Run the app:**
   ```bash
   flutter run
   ```

---

## 🔒 Privacy First
Beluga Health is built on the philosophy that your health data is **yours**. There are no cloud servers, no data selling, and no internet connection required for the core functionality. Everything is stored locally.
